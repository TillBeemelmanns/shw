# Assets

`countries-110m.json.gz` is the base map behind `geojson` / `topojson` code blocks: country outlines from
[Natural Earth](https://www.naturalearthdata.com/) (1:110m, public domain) as TopoJSON, taken from
[world-atlas](https://github.com/topojson/world-atlas) 2.0.2 (`countries-110m.json`) and gzip-compressed.
